長照與社福 MamaCare 功能介紹　2026.09

MamaCare

月子中心管理系統

寶寶與媽媽照護紀錄、護理交班、訂房收費、家屬端日報，紙本全面數位化。

使用對象
月子中心・產後護理之家
員工端↗

這是什麼？

MamaCare 是一套給「月子中心／產後護理之家」用的管理系統。它把中心每天要做的事 —— 照顧寶寶、照顧媽媽、護理交班、排班、訂房、收費、訂餐、商城販售、課程報名、耗材庫存、會員點數 —— 全部搬到電腦和手機上，不用再靠紙本和白板。

系統分成兩個入口：

  • 員工端：護理師、管理員每天工作的地方。
  • 家屬端：寶寶的爸爸、阿公阿嬤，用一組通行碼登入，隨時看到寶寶今天的狀況。

手機、平板、電腦都能用（畫面會自動調整大小）。

給「護理師 / 員工」用的功能

1. 寶寶照護紀錄

每天照顧寶寶的大小事都能記下來：

  • 餵奶（喝多少、怎麼餵）、換尿布、量體溫、量體重、黃疸值、洗澡、睡眠，以及呼吸、心跳、血氧、身長、頭圍等生命徵象與膚色、臍帶、溢吐奶、活動力、大便性狀等觀察。親餵可記錄左／右乳各餵幾分鐘。
  • 一鍵快速記錄：例如「換了濕尿布」「大便」「洗澡」「餵奶」，按一下就完成，不用慢慢填表；觀察類欄位用下拉選單。
  • 巡房批次記錄：一個畫面一次記錄多位在住寶寶的體溫與餵食，巡房時不用一位一位切換。
  • 可以上傳寶寶照片。
  • 系統會自動把一天的紀錄整理成寶寶日報：
    • 完整摘要：除餵食、尿布、紅臀、體溫、體重、黃疸外，呼吸、心跳、血氧、身長、頭圍、膚色、活動力、大便性狀等有記錄就一併呈現。
    • 異常提醒：體溫／黃疸超出門檻、紅臀中度以上、餵食間隔過長會在日報上方紅字標示。
    • 可列印／匯出 PDF：日報可一鍵列印或另存 PDF（含摘要、當日紀錄、照片）。
    • 還會畫出體重、黃疸的趨勢圖。
  • 日報可以一鍵發送給家屬（家屬端與 LINE 同步顯示完整摘要與注意事項）。

2. 寶寶位置（嬰兒室／母嬰同室）

清楚掌握每個寶寶現在「人在哪裡」：

  • 每個寶寶都有目前位置：在嬰兒室，或是母嬰同室（抱在媽媽身邊）。
  • 一鍵切換：「抱去給媽媽」／「抱回嬰兒室」，切換時可加註備註。
  • 每次移動都會留下位置異動紀錄（誰、什麼時候、移到哪），隨時可查完整歷史。
  • 記錄照護時可標註是在嬰兒室還是媽媽房做的；不選的話自動沿用寶寶目前位置。
  • 總覽會顯示「嬰兒室幾名、母嬰同室幾名」，並在每個寶寶旁標出目前位置。

3. 媽媽照護紀錄

記錄產後媽媽的恢復狀況：生命徵象、傷口、子宮、乳房、惡露、排泄、泌乳、情緒評估、衛教說明。

  • 一頁式評估：點「一頁式評估」可在同一頁一次填寫生命徵象與全部評估項目，類別欄位（傷口、子宮、乳房、惡露、排泄、泌乳、情緒、衛教）改用下拉選單，減少護理師打字時間；只填需要的項目、留空者不建檔，一次儲存多筆。下拉內容可在「系統設定」自訂。

3-1. 醫師巡診就醫紀錄（小兒科／婦產科）

特約醫師到院巡診時，用標準 SOAP 格式留下正式就醫紀錄，補足「只記錄有沒有通知醫師」的不足：

  • 巡診對象：可選寶寶（小兒科）或媽媽（婦產科），科別可再選小兒科／婦產科／其他。
  • 巡診類型：常規巡診／追蹤複查／不適診視／出院評估。
  • SOAP 欄位：主訴（S，含護理或家屬反映）、理學檢查所見（O）、診斷評估（A）、處置醫囑（P），另有追蹤／回診安排。
  • 轉診／建議就醫：填寫院所即代表需轉診，列表以紅字標示，方便追蹤院外就醫。
  • 巡診醫師可在「系統設定」建立常用名單快選，減少打字。
  • 依科別（小兒科／婦產科）一鍵篩選；每筆都留下記錄者與時間。
  • 為獨立權限模組「醫師巡診」，可單獨授權；刪除僅限管理員。

4. 護理交班（SBAR）

換班的時候，把重要資訊用標準格式（現況、背景、評估、建議）交接清楚，可以依「日期」和「班別」查看，避免口頭交代漏掉事情。

  • 未結待辦會自動列入下一班提醒；可「自動帶入草稿」依當日紀錄產生 SBAR。
  • 列印交班單：可一鍵列印／另存 PDF 當日整份交班單（機構抬頭＋各班別 S/B/A/R＋待辦），交接、存查兩用。

5. 住客管理

管理每位媽媽和寶寶的基本資料，例如預產期、生產方式、飲食禁忌、醫療注意事項，隨時可以修改。

6. 房務與訂房

  • 看各種房型、房價、目前哪幾間空著。
  • 訂房時系統會自動檢查檔期有沒有撞到，並依入住天數自動算出總金額。
  • 完整的入住、退房、取消流程。
  • 入住前準備：已簽約到實際入住之間，預約那筆可按「入住前準備」一次調整床位／房間、入住退房日、膳食類型與飲食注意、寶寶入住日，確認無誤後可直接「儲存並辦理入住」。

6-1. 排床（預定床表 / 實際入住床表）

專門的「排床」頁，用房間 × 日期的格狀表呈現兩種床表，一鍵切換：

  • 預定床表：含所有已預約與入住中的訂房，看未來檔期怎麼排。
  • 實際入住床表：只顯示實際已辦理入住者；已預約但還沒入住的會以斜線標示「待入住」，一眼看出計畫與現況的落差。
  • 上方統計今日預定床數、實際入住、待入住與總床位。

6-2. 房務清潔

讓客服與清潔人員同步掌握每位在住媽媽的需求：

  • 住客需求：登記勿擾時間、需求項目（哺乳衣、定時清垃圾、加床被…）、其他備註，清潔人員即時可見。
  • 清潔任務：可排定清潔/備品任務（指定房間或公共區域）、設定日期、完成打卡，逾期會標示。
  • 「房務清潔」為獨立權限模組，可單獨授權給清潔人員。

7. 收費帳務

每一筆訂房都看得到：

  • 應收：合約金額 ＋ 額外加購的消費 −（寶寶未入住扣抵）。
  • 已收：訂金 ＋ 後續繳費。
  • 還差多少沒收：未結餘款會拆成「合約未結」與「加購未結」分別顯示。

加購和繳費都會記下「是誰經手的」，刪除紀錄只有管理員能做，避免出錯或亂改帳。

  • 寶寶入住日連動：媽媽已入住但寶寶還沒到院的期間，系統每日自動扣抵（金額可在系統設定調整，預設 1,000 元／日，上限不超過總住宿天數），扣抵會反映在應收與帳齡、儀表板，退費試算也會一併計入。
  • 加購明細可列印：收費明細頁可一鍵列印加購消費明細（含機構抬頭、品項、單價、數量、經手人、合計）。

8. 膳食管理

  • 系統會自動算出今天有哪些媽媽在住。
  • 早、午、晚三餐，點一下就存檔，並會自動帶入每個人的飲食禁忌。
  • 每一餐可標記訂餐狀態（備餐中／已出餐／取消）並加備註，備餐進度一目了然。
  • 可以列印廚房備餐單，上面有各餐的份數統計，廚房照著做就好。
  • 適合把月子餐外包給多家廠商的中心：備餐單會依廠商分別列出各家明細，並提供區間請款統計。

8-1. 月子餐（自家廚房／分階段菜單）

給有自己廚房、要做結構化月子餐的中心：

  • 餐期階段：依每位媽媽的產後天數自動判定階段（例：排惡露→補氣血→健脾胃→養氣補身），階段天數可自訂。
  • 一日多餐含點心：餐別可自訂（預設早餐、早點、午餐、午點、晚餐、宵夜）。
  • 每日菜單：每餐可分「餐期×飲食類型」建立菜色（主食／主菜／藥膳湯品／鮮蔬／甜品／飲品），可一鍵複製前一天。
  • 供餐總覽／廚房備餐單：自動對應每位媽媽的階段與飲食類型，列出當餐菜色與份數統計，可列印。
  • 家屬可看：家屬端「月子餐」分頁能看到媽媽今天每一餐的菜色。
  • 我要換餐：家屬可在月子餐頁線上申請換餐（選餐別、希望更換內容、原因），由護理站／膳食部審核，家屬可看到同意或婉拒結果。

9. 參觀預約（含一鍵簽約建檔）

登記來參觀的潛在客戶（參觀時間、預產期、從哪知道我們的），並追蹤狀態（待參觀 / 已參觀 / 已簽約 / 未成交），還能看本月參觀人數和簽約率。

  • 多條件篩選：可依關鍵字、狀態、來源、參觀日期區間快速過濾。
  • 追蹤紀錄（log）：每位客戶的備註改為追加式時間軸，每筆都帶時間與經手人，狀態變更也會自動寫入，跟進歷程不會被覆蓋。
  • 下次跟進日＋提醒：可設定每位潛客的下次跟進日期，到期（含逾期）自動列入總覽待辦提醒，不漏追。
  • 對外線上參觀預約：提供公開頁 /tour-booking.html，潛在客戶可自助填寫姓名、電話、希望參觀時間直接送出，自動進到參觀預約（來源標記「線上預約」），並可即時 LINE 通知值班。
  • 按下「已簽約」會直接跳出訂房表單，自動帶入客戶的姓名、電話、預產期。
  • 選好房間和入住／退房日，系統會自動算出合約總額。
  • 確認後一次完成：建立媽媽資料、建立訂房、把參觀轉為已簽約，並跳到房務頁；不用再重複輸入一遍客戶資料。

10. 排班與人力檢核

  • 排三班、七天的班表。
  • 系統會自動算出每天有幾個寶寶在住，對照法定人力比，提醒你人手夠不夠，避免違規。

11. 總覽儀表板

一打開就看到中心今天的整體狀況：

  • 入住率、在住媽媽和寶寶人數、今日照護筆數。
  • 還沒收的款項、這個月已收的錢。
  • 每個寶寶今天的照護狀態（最後一次餵奶、餵幾次、尿布、最後體溫）。
  • 今日訂餐彙總（有人沒訂會提醒）。
  • 異常警示（體溫、黃疸超過設定值會跳出來）。
  • 人力比檢核、近期退房、即將入住、待參觀名單、近 30 天入住率走勢圖。

12. 評鑑月報（管理員專用）

一鍵產生月報：住房率、照護與交班統計、每天的人力比是否合規（不合規的日期會標出來）、異常事件清單。可以列印或匯出檔案，直接拿來當衛福部評鑑的佐證資料。

12-1. 營運報表（每日入住率＋品管指標）

獨立的「營運報表」頁，選月份即可看：

  • 每日入住率：逐日佔床／總床、入住率長條與當日人力配置是否符合，可列印、可匯出 CSV。
  • 評鑑品管 7 大指標：依衛福部產後護理機構評鑑精神彙整——平均入住率、住民跌倒事件率（每千住民日）、院內感染事件率、手部衛生遵從率、新生兒篩檢異常追蹤完成率、顧客滿意度、護理人力配置達標率。指標定義與分母可依各中心評鑑基準調整。

13. 商城（商品販售）

把中心要賣的東西搬上線，家屬自己就能下單：

  • 商品上架／下架：建立商品（品名、分類、售價、成本、圖片、說明），一鍵上架或下架。
  • 庫存管理：可選擇是否管控庫存；確認訂單時自動扣庫存。
  • 家屬線上購買：家屬在「商城」分頁瀏覽上架商品、加數量、送出訂單。
  • 護理站確認入帳：員工確認訂單後，金額自動列入該媽媽的收費帳單，於現場結算（也支援員工代客下單）。
  • 批次匯入商品：可用 CSV 一次匯入大量商品（以品名為鍵，已存在則更新、否則新增）。

14. 耗材庫存（內部進銷存）

管理尿布、奶粉等內部物料（和商城賣的商品是兩回事）：

  • 建立耗材品項與安全庫存；庫存低於安全量會跳出補貨提醒。
  • 進貨／領用／盤點都會留下異動紀錄（誰、什麼時候、剩多少），隨時可查。
  • 另有更完整的備品庫存管理模組，見「近期新增功能」。

15. 課程與服務

中心的媽媽教室、產後服務都能線上報名收費：

  • 建立課程／活動（可設時間、地點、名額）或加購服務（泌乳諮詢、產後 SPA、寶寶攝影、彌月禮盒…）。
  • 家屬在「課程／服務」分頁線上報名，護理站確認後自動列入帳單。
  • 課程名額自動控管，額滿不能再報。
  • 課程行事曆：可切換「清單／行事曆」，用月／週檢視排定的課程；管理員可點空白日期新增課程、拖曳課程改期，點課程也能直接代客報名。家屬端「月子餐」頁另有近期課表可看。

16. 會員與優惠（點數、優惠券）

每位媽媽入住即為會員，消費更有感：

  • 會員點數：每位媽媽有專屬會員編號與點數；消費回饋點數，下次可折抵（回饋率可在系統設定調整）。
  • 優惠券：可發行固定金額或百分比折扣券，設定最低消費、使用次數與效期。
  • 家屬在商城結帳時可輸入優惠券、折抵點數，系統即時試算應付金額；折抵與回饋都會反映到帳單。

17. 系統設定（管理員專用）

中心的各種參數都能自己調，不用找工程師：

  • 機構名稱、人力比、體溫／黃疸的警示門檻。
  • 餵食方式、生產方式、繳費方式、常用加購項目、餐點選項。
  • 點數回饋規則（每滿多少元回饋 1 點、1 點折抵多少元）。
  • 月子餐：餐別、飲食類型、餐期階段（依產後天數）。
  • LINE 推播的設定。

18. 帳號與權限（管理員專用）

後台帳號可分權限，不必每個人都看得到全部功能：

  • 管理員：全權帳號。
  • 一般員工：由管理員逐一勾選可用模組（如：廚房只開「膳食／月子餐」、出納只開「收費帳務／電子發票」、護理師開照護相關模組）。
  • 內建角色範本（護理師／出納／廚房／行政）可一鍵套用再微調。
  • 權限在前後台雙重把關：沒權限的人看不到該功能選單，後端 API 也會擋下；系統並保護「至少保留一位管理員」。

19. 衛福部表單通報

把營運資料整理成可申報主管機關的標準月報表：

  • 一鍵產生產後護理機構月報表：總床數、可用床日數、佔床日數、佔床率、月初在住／本月新收／出住／月底在住人數、平均住房日數、嬰兒照護人日、人力比與不合規天數、手部衛生遵從率、清消次數、群聚數、異常事件、待追蹤篩檢…
  • 可下載 Excel（供人工上傳各地衛生局系統），或「檢視欄位」即時預覽。
  • 若設有衛生局／加值平台 API，可自動上傳並於失敗時自動重試補送，保留回執編號與上傳紀錄；未設定時為本地模式。

20. 員工證照管理

  • 登記每位員工的證照（名稱、證號、發證單位、發證日、到期日）。
  • 到期提醒：到期前 N 天（可設定）會在總覽「待辦提醒」自動跳出，過期則標紅。

21. 電子問卷／滿意度調查

  • 自訂問卷題目（評分、單選、文字），開放或關閉。
  • 家屬在家屬端「滿意度問卷」分頁填寫（每份只能填一次）。
  • 後台即時看統計：平均評分、選項分布、文字回饋。
  • 退房自動推問卷：媽媽退房時，系統自動把問卷邀請推給家屬（已綁 LINE 者直接收到），回收率更高。

22. 完整照護紀錄欄位

照護紀錄涵蓋產後護理之家該追蹤的細項，不只餵奶／尿布：

  • 寶寶生命徵象：體溫、呼吸、心跳、血氧（SpO₂）。
  • 生長測量：體重、身長、頭圍、黃疸值（自動畫趨勢圖）。
  • 觀察評估：膚色／發紺、臍帶狀態、溢吐奶、活動力、大便性狀（胎便／黃稠／水樣／血絲…）、紅臀程度。
  • 媽媽：生命徵象、血壓、脈搏、傷口、子宮、乳房、惡露、排泄、泌乳指導、用藥、情緒評估、衛教。
  • 上述類別選項（膚色、臍帶、大便性狀…）都可在系統設定自訂。

23. 合約電子簽署

  • 由訂房＋範本一鍵產生合約，家屬以簽署連結手寫簽名完成（留存簽署人、時間、IP 佐證）。
  • 可重新編輯／重新簽署：未簽署的可直接改內容；已簽署的可以原文為底建立新版重簽，原合約自動作廢並保留版本鏈，符合存證要求。
  • 經手人欄位：建立合約時可選擇經手人（業務／客服），列表、搜尋與列印都會顯示，責任歸屬清楚。

24. LINE／Facebook 客訊整合（CRM）

把官方帳號與粉專的訊息收進同一個後台收件匣：

  • 雙向訊息：自動接收 LINE／FB 來訊，後台直接回覆，推回原通道。
  • 自動對應住戶：已綁定 LINE 的家屬來訊自動連到個案；未對應者列為潛在客戶，可手動指定。
  • 未讀會進總覽提醒，不漏接客戶與家屬訊息。

25. 經營分析儀表板（管理員專用）

不只看單月，更看趨勢：

  • 入住率、每月實收、參觀簽約轉換率、商城毛利的近 6～24 個月走勢圖。
  • 逐月明細表（新收／退住人數、營收、毛利…），可列印，幫經營者掌握成長與淡旺季。

26. 應收帳齡與催收

  • 帳齡分析：未結帳款依逾期天數分級（未到期／1–30／31–60／60 天以上），逾期金額一目了然。
  • 一鍵催收：對逾期住戶發送催收提醒（家屬留言＋已綁 LINE 者直接收到），並記錄催收時間。

27. 日常更順手

  • 智能餵奶提醒：寶寶距上次餵奶超過設定時間，自動在總覽提醒「該餵奶了」。
  • 交班自動彙整：交班時可一鍵帶入 SBAR 草稿（自動統整當日餵食、換尿布、異常與待辦），不必從頭打字。

28. 名人／顧客推薦牆（對外行銷）

  • 後台管理推薦內容：人物姓名、稱號、推薦語、照片、來源連結（FB／IG）、影片連結，可上架／下架與排序。
  • 內建公開展示頁（/testimonials.html）：自動以上架內容呈現推薦牆，可放進官網或直接分享連結；照片上傳即時生效。

29. 營運優化（日常更順手）

  • 房況時間軸：甘特圖式檔期總覽，哪間房、哪段時間有人一眼看懂，排房不撞期（點訂房可看帳務）。
  • 異常即時通知：寶寶體溫／黃疸超過設定值時，除了儀表板提醒，還能即時 LINE 通知值班人員。
  • 耗材叫貨單：低於安全庫存的耗材一鍵產生建議叫貨量清單，可列印交供應商。
  • 評鑑月報一鍵 PDF：月報可直接匯出 PDF佐證檔（也保留列印／CSV）。
  • 交班待辦不漏接：交班時填的待辦事項，未完成會自動列入「未結待辦」與總覽提醒，做完再勾掉。
  • 快速輸入（減少打字）：常填欄位提供「快選建議」下拉，直接點選也能自己打——涵蓋新生兒醫療（藥品／給藥途徑／接種部位）、異常事件（發生地點）、感染管制（稽核區域／對象、清消區域／消毒方式）、員工證照（證照名稱／發證單位），以及商城／耗材／課程的分類（自動帶出現有分類）。建議選項皆可在「系統設定」自訂。
  • 更完整的待辦提醒：待辦提醒再加入漏給藥（高）、疫苗待接種、體溫連續偏高／體重連續下降的趨勢預警、參觀跟進到期、媽媽預產期將近／寶寶滿月的關懷，讓護理與客服都不漏事。
  • 家屬留言即時通知：家屬在入口「聯絡護理站」留言時，除了總覽提醒，還能即時 LINE 通知值班人員，回覆更即時。
  • 入住歡迎與關懷：媽媽辦理入住時自動發送歡迎關懷訊息到家屬端（有家屬帳號才送、不重複）；預產期將近與寶寶滿月則以待辦提醒方式提示，方便主動關懷。
  • 臨床紀錄單列印：護理交班單、新生兒醫療紀錄單（給藥／疫苗／篩檢／光療）、寶寶日報都可一鍵列印或另存 PDF。
  • 加到主畫面（PWA）：員工端與家屬端都可「加到手機主畫面」像 App 一樣開啟，並支援基本離線檢視。

房間資料管理

  • 預約參觀時段設定：設定一般開放時段（起訖、每時段分鐘、每時段人數），以及指定日期時段或不開放日。

備品庫存管理

比耗材庫存更完整的備品進銷存，共六個作業頁：

  • 備品名稱設定（產品編號、分類、單位、建議售價、是否標示有效期、是否開放前台銷售、安全庫存），支援CSV 批次匯入。
  • 進貨入庫（可記進貨廠商、有效日期）、領取出庫（可記使用區域）。
  • 進出明細表、庫存盤點（顯示期初／入庫總數／出庫總數／目前庫存）、盤點明細表，皆可查詢、分頁與匯出 CSV。

員工基本資料

比「帳號管理」更完整的員工檔案（與帳號管理並存）：

  • 記錄部門、群組、分類、等級、考勤卡號、手機、住家電話、E-mail、分機、離職日等。
  • 登入權限 0–5 自動對映系統角色（0 停用、5 管理員、1–4 一般員工）；醫師／護理等旗標對映對應模組權限。
  • 可依姓名／等級／權限／身分證號、分類、部門查詢（含已離職）。

產後報表與護理紀錄查詢

彙整多份產後營運報表（每日收款、營收分析、住宿率、入住統計、退訂統計、參觀成交率…）與護理紀錄查詢（媽媽／寶寶護理、母乳哺育率、親子同室、感控品質、愛丁堡憂鬱量表統計…），依日期／條件查詢。

給「家屬」用的功能

家屬拿到一組 8 碼通行碼就能登入，看到自己寶寶的狀況：

  • 今日摘要：寶寶今天過得怎麼樣。
  • 完整照護時間軸：餵奶、換尿布、量體溫…一筆筆都看得到。
  • 照片牆：護理師上傳的寶寶照片。
  • 成長趨勢圖：體重、黃疸的變化。
  • 月子餐：看媽媽今天每一餐的菜色（產後第幾天、餐期階段），並可線上申請換餐、查看審核結果；另有近期課表。
  • 商城：瀏覽商品、加入購物車、線上下單，可用優惠券與點數折抵，並查看自己的訂單與會員點數。
  • 課程／服務：瀏覽並報名中心的課程與加購服務，追蹤報名狀態。
  • 滿意度問卷：填寫中心的問卷與滿意度調查。

家屬端看不到內部護理人員的資訊，保護員工隱私，也讓家屬安心透明。 商城下單與課程報名都需護理站確認後才入帳，費用於現場結算。

LINE 官方帳號串接（使用方式）

中心的 LINE 官方帳號選單有兩顆按鈕：「預約參觀」給還沒入住的媽咪用、「產後服務」給已入住寶寶的家屬用。

預約參觀（用戶端）

還沒入住的媽咪加入官方帳號好友後，全程在 LINE 裡完成預約：

  1. 點選單「預約參觀」，開啟預約頁面。
  2. 填寫資料：媽咪姓名、連絡電話、胎次、預產期，按「儲存」。
  3. 驗證手機：系統把 6 碼驗證碼傳到您的 LINE 聊天室，切回對話查看後回頁面輸入（10 分鐘內有效，可重新發送）。
  4. 選擇時段：行事曆只顯示有開放且尚有名額的日期，點日期後選擇時段（會顯示每時段剩餘組數）。
  5. 送出後立即收到「預約參觀安排中」卡片訊息（含預約日期、時段、預產期、胎次）。
  6. 中心確認後，再收到「預約參觀已確認」訊息，就完成囉！

預約參觀（員工端）

  • 用戶送出的預約會自動建立潛在客戶檔（以電話比對，已有客戶則自動關聯），並出現在：
    • 客戶管理頁查詢區下方的紅框「待確認預約（LINE）」區塊；
    • 預約參觀行事曆與參觀預約列表（黃色「待確認」標示）。
  • 點「確認」：系統自動發送「預約參觀已確認」LINE 訊息給客戶；點「取消」需填原因。
  • 可預約時段完全依照「預約參觀時段設定」：一般開放時間（起訖、每時段分鐘、每時段人數）＋指定日期時段／不開放日；已被預約（含待確認）的額度會自動扣除，不會超收。
  • 若有設定值班通知目標，收到新預約時同步 LINE 通知值班人員。

產後服務（家屬端）

後台完成寶寶報喜建檔並建立家屬帳號後即開通。家屬點選單「產後服務」：

  • 第一次使用（未綁定）：機器人會請家屬直接在對話輸入護理站提供的 8 碼家屬通行碼，輸入即綁定完成。
  • 已綁定：直接回覆家屬入口網頁連結，點開自動登入，可看寶寶日報、照護時間軸、照片牆、成長趨勢、月子餐、商城等。
  • 每日 10:00 自動推播（時間可在系統設定調整）：綁定 LINE 且寶寶在住的家屬，每天自動收到前一日的寶寶日報摘要（餵食、尿布、體溫、體重、黃疸、沐浴…）與成長趨勢（體重較前次增減、最新黃疸、近 7 日平均餵食次數），並附家屬入口連結。
  • 員工在寶寶日報頁按「發送日報」時，綁定 LINE 的家屬也會直接在 LINE 收到；沒綁定的家屬一樣可從家屬入口自己看。

雙向客訊（LINE／FB 客訊）

用戶在官方帳號輸入的一般訊息會進入員工端「LINE／FB 客訊」統一收件匣，可直接回覆（推回 LINE）、對應住戶或標示潛在客戶；選單關鍵字（預約參觀／產後服務／通行碼）由系統自動處理，不會塞進收件匣。

中心要設定什麼（一次性）

  1. 到 LINE Developers 建立 Messaging API channel，把 Channel Access Token 與 Channel Secret 填入系統設定。
  2. Webhook 網址設為 https://mamacare.crownai.ink/api/webhooks/line 並啟用。
  3. 官方帳號圖文選單設兩顆按鈕：「預約參觀」＝傳送文字「預約參觀」；「產後服務」＝傳送文字「產後服務」（也支援 postback action=tour_booking／action=family_portal）。
  4. （選用）建立 LIFF：Endpoint 設為 https://mamacare.crownai.ink/tour-booking.html，LIFF ID 填入系統設定後，選單可直接開啟預約頁、不經對話回連結。
  5. 系統設定填對外網址（public_base_url）、異常／值班通知 LINE 目標、家屬日報自動推播時間（預設 10:00，留空停用）。

就算完全不設定 LINE，整套系統也能正常離線使用；線上預約與家屬入口仍可用一般網頁操作。
